A · Ctrl+hover filters the profile

  • Rest the pointer on the profile panel and hold Ctrl (⌘ on macOS): the panel shows only the selected columns' cards. Release and every card comes back, scrolled where it was.
  • The same shape as Peek on Hover in Object Explorer and the editor: a modifier gesture with a target (here, the panel), rebindable to Shift in Shortcut Mapping (gestures.ts, output.profilePeekHover).
  • Scoped to the panel on purpose: Ctrl held over the grid is Ctrl+click (add to selection) and Ctrl+C, so Ctrl anywhere would flash the panel on every copy.
  • Con: invisible until you know it; nothing a keyboard user can hold, so it needs a command anyway.

B · The profile follows the selection

  • Always on, no modifier. The cards of the selected columns get an iris edge; the active cell's column card is shaded and scrolled into view as the selection moves (arrow keys, clicks, header clicks).
  • Two-way: clicking a card selects that column in the grid and scrolls the grid to it (as SSMS-style object sync does).
  • A multi-column selection marks each card; the scroll goes to the active column only, so a big selection does not jump around.
  • Con: on a 200-column result you still scroll past unselected cards to compare two columns.

C · "Selected Columns Only" toggle

  • A toggle in the panel's head (and a command, Column Profile: Selected Columns Only, in the palette and the grid menu). On: the panel lists only the selected columns' cards, updating as the selection changes.
  • A strip says "2 of 10 columns · Show all"; a single-cell selection still shows its column, so the panel is never empty.
  • Sticky per results pane; a new run keeps it. Profiles are still computed for every column, so turning it off is instant.
  • Con: one more control; a quick look needs two clicks (on, then off).

Recommended · B always, C as the toggle, Ctrl+hover peeks CRecommended

  • B by default: highlight and scroll answer "where is this column's profile?" with no learning.
  • C for comparing a few columns of a wide result, sticky and reachable from the keyboard and the palette.
  • Ctrl+hover on the panel flips C for as long as Ctrl is held: our universal "peek", so the quick look needs no clicks. With C on, Ctrl+hover shows all columns.
  • The strip names the state while peeking ("Peeking 2 selected columns · release Ctrl to show all"), so the panel never silently changes.

Keyboard and accessibility

  • Keyboard: Column Profile: Selected Columns Only is a catalogue command (no default key proposed; bindable). Column Profile: Reveal Column (Ctrl+Alt+P proposed, grid focus) moves focus to the active column's card; Escape returns to the grid.
  • Cards become one Tab stop with Up/Down between them; Enter on a card selects that column in the grid. Each card's name says "selected" (aria-current for the active column).
  • Filtering or peeking announces once in a polite live region ("Showing 2 of 10 columns"), never per selection move.
  • Smooth scrolling only without prefers-reduced-motion; the edge and shading use iris and selection tokens, with a 2px edge so forced-colours mode keeps it (Highlight).
  • Ctrl going up with the window unfocused is handled as Peek does (KeybindingService blur drops the modifier), so the panel never stays stuck filtered.

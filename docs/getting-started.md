# Getting Started

Open **Help > Getting Started**, or search for Getting Started in the command palette. The read-only tab contains
offline guides for connecting to SQL Server, running a query, and working with results. Search matches titles,
summaries and topic keywords. Related guides link the workflows together.

Command names, menu paths, shortcuts, mouse gestures and option values come from Varia's current catalogs and
applied window settings. Each shortcut names its lesson context: an editor shortcut is described for focus in the
SQL editor, even while you are reading Help. A scoped override that shadows another shortcut suppresses the
shadowed label. Unbound commands still show their menu or palette path.

The examples contain fictional data. Changing sample authentication, query selection, sorting or filtering makes
no connection or SQL request. **Open Connect dialog** and **Open a blank query** are explicit entry points to the
real application. Options links open the relevant page; changes apply through the normal Options workflow.

The guide tab has no SQL model and cannot be saved or recovered as a query. Reopening the same guide keeps its
section; choosing another guide starts at its beginning. Returning to All guides clears the search. Closing the tab
or restarting clears its reading state. Guides do not preserve query results or store completion progress.

To add or update a guide, follow [Help authoring](help-authoring.md).

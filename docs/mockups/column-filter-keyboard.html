The idea

Everything the checklist does is reachable from the keyboard without Tab: ↓ from the search enters the values, ← from the values enters the action list, → goes back, ↑ from the top of either list returns to the search, and typing in a list goes to the search. Tab still reaches the condition and the buttons.

The action list replaces the Select all / Select none buttons and changes with what you are doing, and each action says exactly what it will touch, with a count, so a search never makes "Select none" mean "only these".

The action list, by context

No searchTick all · Untick all · Invert ticks
Search appliedTick the N matches · Tick only the N matches · Untick the N matches — then, apart: Tick all M values · Untick all M values
2 or more values selectedA first group: Tick the S selected · Untick the S selected · Tick only the S selected

"Tick only…" unticks everything else, the way Excel's search does by default; "Tick the matches" adds to what is ticked (Excel's "Add current selection to filter"). Enter or Space runs the highlighted action; the focus stays in the action list.

Selection is not ticking

Ticked (the check box) is what the filter keeps; OK applies it. Selected (the highlight) is the rows you are about to act on. A plain click still ticks a row, as today, and makes it the only selected row. Arrow keys move the selection without ticking. Space ticks the whole selection: if any selected row is unticked it ticks them all, otherwise it unticks them all (Windows Explorer's rule for check boxes).

Feedback 3: filter several columns at once?

Recommendation: no multi-column popover. One list of values only makes sense for one column; Excel and SSMS both filter the active column, which is what Alt+Down does now. Filtering several columns at once is already Filter for Selected Values (one filter per selected column). What would help is moving between columns without closing: optionally, Alt+→ / Alt+← in the popover applies this column's filter and opens the next or previous column's. I would leave it out unless you want it.

Questions for you

  2. Should Enter in the search box be OK (Excel does this, filtering to the ticked matches)? Today it does nothing.
  3. Default width grows from 300 to about 440 px for the action list (your resized width is kept).
  4. Add Invert ticks, or keep the no-search list to Tick all / Untick all?
  5. Include Alt+→ / Alt+← to move to the next column's filter?

Under the hood: a selection over a long list (Shift+End across a million values) is kept as ranges, and ticking it sends the ranges to the backend in one bounded request, not every value.

Drag a server onto a query tab

Dragging a server from Object Explorer onto a query tab, or onto its editor, moves that query to the server, as Query › Change Connection… does. Pick a scene; the ▶ scenes play the drop, ↻ Replay runs it again, and Slow motion stretches it to about four seconds.

Your system asks for reduced motion (Windows: Settings › Accessibility › Visual effects › Animation effects off). Varia animates anyway by default; only with its Options setting that follows the system turned on does the server swap instantly. Untick "Animate even with reduced motion on" to preview that.

How it behaves

  • Starts when a server row is dragged. Every query tab shows a dashed socket under it; tabs that are not queries dim. Reordering servers in Object Explorer still works during the same drag, so one gesture does either.
  • Over a query tab the tab lifts and fills with the accent, its socket pulses, and a card names the move: old server struck through → new server, and the database it will use. Hovering does not switch tabs.
  • Dropping runs targets.changeConnection, the same path as Change Connection…: the query's session ends first, and the query opens on the new server's default database (the database remembered for that server when it had one). The tab becomes the active tab and the editor takes focus.
  • The animation (≈ 0.9 s, one decelerating curve, no overshoot, no layout shift): the drag image glides the short way into the tab as the tab's lift eases away; a soft wash in the new server's colour passes behind the tab's text while the server name cross-fades under it, so the change is covered rather than performed; the colour rule on the tab's top edge eases out from the centre; the SID badge dims while the old session ends and returns with the new session's number; the status bar and a quiet toast follow. Dropping on the editor sends the plate into the query's tab on a slight arc, shrinking as it goes, while the tint and frame fade; the tab's swap starts as it lands. Varia plays it even when the system asks for reduced motion, unless the Options setting that follows the system is turned on.
  • Open transaction: the existing prompt asks Commit, Roll Back or Cancel before the session ends; Cancel leaves the query where it was.
  • Running query: the tab refuses the drop (no-entry cursor, no socket pulse) and the card says to stop the query first. The query is never stopped for you.
  • Same server: refused quietly; the card says the query is already there, so the session and its temp tables are kept.
  • Not a query (Activity Monitor, Table Designer, Properties, Peek, SSIS pages): refused; they keep the server they were opened for.
  • Production: the card shows the server's environment tag; no extra confirmation (the move itself changes nothing on either server).
  • Over the query editor the whole editor becomes the drop target: it tints with the accent behind a marching dashed frame, and a plate in the middle names the move (the server's glyph with a halo in its colour, old → new server, the database). Dropping shrinks the plate into the query's tab, which then plays the same swap as a drop on the tab. Running, same-server, not-a-query and Production cases show on the plate as on the tab card.
  • Ctrl held over the editor (⌥ on macOS) steps the overlay aside for a text drop: the server's name goes in at the caret shown, as dragging a table into the editor inserts its name. The plate's last line says so, and pressing or releasing Ctrl mid-drag switches at once.
  • Disconnected servers cannot be dragged onto tabs (their rows offer Reconnect instead). A server dropped on the tab strip's empty space opens a new query on it (decided).
  • Keyboard and screen readers: Change Connection… stays the keyboard path; the drop is announced ("Orders report.sql moved to REPORTING-SQL").

Decided with the owner

  • One code path: every drop calls targets.changeConnection, the same flow as Query › Change Connection…, so later changes to it (database choice, session prompts) apply to both.
  • Empty tab-strip space: dropping a server there opens a new query on it.
  • Database rows: dropping a database row (AppData under REPORTING-SQL) on a query moves it to that server and that database in one step: Change Connection, then Change Database.
  • Production: the environment tag in the card is enough; no extra prompt.
  • Editor drop: moves the query by default; holding Ctrl (⌥ on macOS) inserts the name at the caret.
  • Animation: the full sequence, polished to feel calm and fluid: it smooths the change over rather than showing off (this version).
  • Reduced motion: Varia animates by default even when the system asks for reduced motion; an Options setting, off by default, makes it follow the system.

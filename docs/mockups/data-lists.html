Every local grid

  • Click, Shift+click, Ctrl+click; drag a block; click a header to select its column.
  • Ctrl+A, Ctrl+C, Ctrl+Shift+C: the results grid's commands, with the user's remapped keys.
  • Arrows, Home/End, PageUp/PageDown, Ctrl+Home/End; Shift extends.
  • Drag a header edge to resize; double-click it to fit.
  • Header sort (Shift+click adds a key), numbers by value.
  • No Filter, Pivot, Profile, Transpose, Compare or Open Value: those stay with query results.
